# Friends

A static multi-brand website project for commercial and industrial equipment distribution, focused on scientific, medical, pharmaceutical, and laboratory products.

## Project overview

This project contains several landing pages and company profiles for partner brands such as Africalabo, CDC, Dream, Excalibur, Fabrice, Kambeu, Labotech, Sinefo, Spiral, Trans, and World. Each page presents a company identity, product focus, and contact information in a polished, brochure-style layout.

The website is built as a front-end static site using HTML and assets such as logos, product images, and shared styling. It is intended to showcase businesses and equipment categories rather than relying on a backend or database.

## Main purpose

- Promote medical and scientific equipment suppliers
- Present company profiles and product categories
- Provide a professional online storefront for partner brands
- Serve as a lightweight static website for easy deployment and maintenance

- `fabrice.html` / `fabrice2.html` — Fabrice pages
- `kambeu.html` / `kambeu2.html` — Kambeu pages
- `labotech.html` / `labotech2.html` — Labotech pages
- `sinefo.html` / `sinefo2.html` — Sinefo pages
- `sipral.html` / `spiral2.html` — Spiral pages
- `trans.html` / `trans2.html` — Trans pages
- `world.html` — World page
- `trans/` and `unic/` — additional subpages or product sections
- `logo-*.avif` — brand logos
- `*.avif` product images and marketing assets

## Run locally

Because this is a static website, you can open any HTML file directly in a browser.

Example:

```bash
start index.html
```

Or open the project folder in a browser and browse the desired landing page.

## Notes

This project is designed for marketing and presentation purposes and does not currently include a CMS, API, or database layer.
